# FPV-Rover V2.0: source

The original download of FPV-Rover V2.0 (Tank) by Markus_p, the design the first tank was printed from:
- Printables model 3150: https://www.printables.com/model/3150-fpv-rover-v20-tank
- Instructables: https://www.instructables.com/id/FPV-Rover-V20

The license is CC BY-NC-SA 4.0, per the saved Printables page.

- `3150-fpv-rover-v20-tank-….pdf` is the saved Printables page.
- `FPV Rover V2.0 - Instructables guide.pdf` is the saved Instructables build guide. It was renamed on
  2026-09-26 because the original name had a colon, which Windows can't check out.
- `alternate-wheel-mounts/` holds the two 41-tooth bevel gears, which Zach's old folder filed as
  "alternitive wheel mounts".
- The other 26 STLs are as downloaded.

The parts as used on the robot, with Zach's edits, are in FPVTank_Control's `docs/chassis/parts/`
until phase B moves them to `chassis-v1/`.
